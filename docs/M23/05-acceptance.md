# 05 - Acceptance

- A designer can scaffold an approval workflow for a catalog-created app document type.
- The generated workflow appears in Designer and is editable.
- Generated worklist views appear in the runtime navigation.
- An author can create and submit a document.
- A non-approver cannot approve or reject.
- A selected approver principal can approve or reject.
- Workflow history records transitions.
- Existing Expense workflow behavior remains unchanged.
- Template export includes generated workflow and worklist views.
- Build and unit tests pass; e2e/deploy status is recorded.
