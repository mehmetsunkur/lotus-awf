# 01 — Scope

## In scope

- Client-side route parsing/building without adding a router dependency.
- Expense view routes.
- Expense document routes.
- Expense design routes for forms, views, and workflows.
- Browser back/forward for in-app route changes.
- Deploy static fallback checks for deep routes.

## Out of scope

- Generic multi-app routing.
- Search query/filter URL state.
- Conflict/revision deep links.
- Workflow-action routes.
- Signed/shareable external links.
